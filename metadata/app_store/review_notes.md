# App Review Notes

SKtimer is a fully offline macOS timer. It does not require an account, does not connect to any network service, and does not collect data.

- Category: Productivity
- Price: Free
- Age Rating: 4+
- Privacy: Data Not Collected
- Network access: None
- In-app purchases: None
- Ads or analytics: None
- Permissions: local notifications; optional user-selected audio file for custom notification sound, copied and stored locally
