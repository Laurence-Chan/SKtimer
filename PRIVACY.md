# Privacy Policy

SKtimer is fully offline and does not collect data.

## Data Collection

SKtimer does not collect, transmit, sell, share, or analyze user data.

The app stores only local app state on the user's Mac:

- Timer records
- Recent timer durations
- Meaningful completion answers and local meaningful time totals
- Menu bar preferences
- Notification permission status managed by macOS

This data is stored locally and is not sent anywhere.

## Network Access

SKtimer does not use network services.

## Analytics and Tracking

SKtimer does not include analytics, advertising, tracking, crash reporting SDKs, or third-party telemetry.

## Notifications

SKtimer uses local macOS notifications to alert the user when a timer completes. Notification permission is controlled by macOS System Settings.

## Contact

For privacy questions, open an issue in the project repository.

# 隐私政策

SKtimer 完全离线运行，不收集任何数据。

## 数据收集

SKtimer 不会收集、传输、出售、共享或分析用户数据。

应用只会在用户自己的 Mac 上保存本地应用状态：

- 倒计时记录
- 最近使用过的倒计时时长
- 倒计时完成后的 meaningful 回答和本地统计
- 菜单栏偏好设置
- 由 macOS 管理的通知权限状态

这些数据只保存在本机，不会被发送到任何地方。

## 网络访问

SKtimer 不使用任何网络服务。

## 分析和跟踪

SKtimer 不包含分析、广告、跟踪、崩溃上报 SDK 或第三方遥测。

## 通知

SKtimer 使用本地 macOS 通知在倒计时完成时提醒用户。通知权限由 macOS 系统设置控制。
